# Sprite Game

An early prototype of a small sprite-based Python game/animation, including custom character sprite art.

## Contents

- `Game/` — `name.py` script plus character images and sound effects.
- `Sprites/` — Piskel sprite source file and exported animation gif.

## Stack

Python.

## Running

```
python Game/name.py
```

Note: this is an early prototype — mostly assets with a single driving script, not a full game yet.
